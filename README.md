# E-Commerce Sales Analysis Dashboard – Power BI

## 📊 Project Overview

This project is an interactive E-Commerce Sales Analysis Dashboard developed using Microsoft Power BI.

The dashboard provides insights into sales, profit, quantity, customers, categories, payment modes, and state-wise performance.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization

## 📈 Dashboard Features

- Sales, quantity, profit and amount KPIs
- State-wise sales analysis
- Monthly profit analysis
- Category-wise quantity analysis
- Customer-wise sales analysis
- Payment mode analysis
- Sub-category profit analysis
- Interactive filters and slicers

## 🔍 Key Insights

- Maharashtra generated the highest sales among the displayed states.
- Printers were the highest-profit sub-category.
- COD represented the largest payment-mode share.
